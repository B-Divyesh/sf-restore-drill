The drill boundary

Small enough for cron. Strict enough to trust.

  1. 01

    Seal the room

    Pull images first, then create a new Docker --internal network. Existing networks and undeclared HTTP hosts are refused.

  2. 02

    Restore the artifact

    Load a plain/custom Postgres dump or a validated volume tar. The original stays read-only; secrets stay in local env files.

  3. 03

    Probe usability

    Run exact SQL expectations and app-level HTTP probes from inside the isolated network—not against production.

  4. 04

    Sign and clear

    Write hashes, image IDs, outcomes, and recovery time to Ed25519-signed JSON; remove containers, volume, and network.
