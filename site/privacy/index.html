Privacy, in plain terms.

Restore Drill is a local command-line tool. The documentation site uses no analytics or tracking cookies.

What the command reads and writes

The command reads the backup, configuration, and credential files you name. It writes reports and signing keys to paths in your configuration. The demo creates its own sample files in a new system temporary directory.

Network use

The command asks your local Docker engine to pull images and run the isolated rehearsal. This static site does not send your backup, configuration, report, or credentials to Restore Drill.

Your choices

Remove local reports, temporary demo files, and browser cache through your operating system or browser controls. Contact the repository maintainers through GitHub for product questions.
