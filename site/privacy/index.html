Policy / effective 28 August 2026

Privacy, in plain terms.

Restore Drill is a local command-line tool. The documentation site uses no analytics or tracking cookies.

What the command reads and writes

A drill reads the backup and credential files named in its configuration. It leaves the backup unchanged. Reports and new signing keys go to configured output paths.

Network use

The demo command pulls its Postgres image before creating test resources. Restore checks run inside its internal Docker network.

The site serves public documentation and recorded sample files. It has no upload controls.

Browser storage

The web walkthrough stores playback progress under a demo-only name. Reset demo clears that state. Leaving the walkthrough clears it too.

A first-party service worker caches public site files for offline reading. It does not cache command data or identify visitors.

Your choices

Remove local reports and temporary demo files through your operating system. Remove the public site cache through your browser controls.
